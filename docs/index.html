Toronto daily temperature forecast

Asking the model…

Fetching recent weather and running the model.

The model runs on a serverless endpoint that scales to zero when nobody is using it, so the first request after a quiet period takes about 10 seconds while it wakes up. Later requests take well under a second.

On days the model had never seen, its average miss was 2.0 °C (3.6 °F). Treat it as a guide, not a weather service.
